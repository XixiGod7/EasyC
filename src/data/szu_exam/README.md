# 深大考题

来源为用户提供的深大 C 语言复习资料图片（`1.jpg`～`6.jpg`）。第 1 张为复习纲要，不计入题数；第 2、3 张为常规题目录，第 4～6 张依次为链表、结构体、文件题目录。资料本身是复习题目目录，未给出可核验的考试年份或完整参考答案。

共 84 题：常规 52、链表 6、结构体 12、文件 14。保留各目录原有编号，`source` 字段记录题型、编号和图片文件名。未将其标注为已核实的官方历年真题。

题目按原目录整理；为支持在线练习，补充了输入输出格式、取值范围、样例和独立编写的标准 C 参考解答。原目录省略的条件、歧义与订正，在对应题目的“补充约定”中说明。常规题 36、37 保留原方程，其中第 37 题的 1.5 作为牛顿迭代初值。

文件题在每次运行独立的沙箱中使用真实 `fopen`、`fread`、`fwrite`、`fseek` 等标准 C 文件操作。题目中已有文件按标准输入初始化，再将操作后的文件读回并打印，方便比较结果；运行结束不保留文件。

目录结构与零基础题库保持一致：`index.json` 引用专题，专题下的 `metadata.json` 引用各个练习 JSON。新增题库统一登记在 `../catalog.json`。

`npm test` 校验目录、编号、唯一 ID 和数据完整性；`npm run test:exercises` 在网站所用的 Clang/WebAssembly 环境中编译 84 个参考解答，并检查所有样例。已安装 GCC 的开发者也可运行 `npm run test:exercises -- --native` 快速检查。
